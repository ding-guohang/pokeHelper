# 商业平台范围：仅限本地手工导出

本目录**不内置**任何商业平台（如 GTO Wizard）的策略数据,也**不自动抓取**它们。
自动登录、遍历或调用商业解算库违反平台条款,本项目一律不做。

允许的唯一路径是**用户本地手工导出**:

1. 你在平台**允许你导出**的界面里,手工导出一份范围文件(如 PioSolver/GTO+ 文本或
   平台记录的导出格式)。
2. 你在本地提供该文件,并附上**授权说明引用**(说明你有权按平台条款使用/导出它)。
3. `convert_local_export.py` **只读本地文件、绝不联网**,记录来源平台、原文件 SHA-256
   与授权说明。
4. 转换结果与随包求解内容走**同样的门禁**:169 手完整、频率(bps)、**同源每行动 EV**、
   假设声明与审核状态。

约束(由 `convert_local_export.py` 强制):
- 输入必须是本地常规文件;URL、symlink、目录一律拒绝。
- 缺少来源平台、授权说明或求解假设一律拒绝。
- **只有频率、没有同源每行动 EV 的文件不能成为可评分内容**——本 App 的评分需要 EV。
- 转换输出仍是 `unverifiedDraft`,除非另行完成具名人工审核(见 `../review-template.md`)。

换言之:平台的数据留在平台;只有你合法导出到本地的文件,才可能在你自己承担授权责任的
前提下,经人工审核后进入训练。
