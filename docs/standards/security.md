# 安全与隐私规范

## 身份与会话

- 支持 Apple 登录和邮箱登录，映射到独立用户 ID。
- 令牌保存在系统安全存储，不写入 UserDefaults 或日志。
- 服务端会话可被用户查看和撤销。

## 数据隔离

- 所有训练事件、能力画像和牌谱查询按用户授权范围过滤。
- 服务端不得依赖客户端传入的 user ID 作为唯一授权依据。
- 导出和删除操作需要重新验证用户身份。

## 敏感数据

- 不提交密钥、生产令牌、未脱敏真实牌谱和用户标识。
- 日志不记录完整牌谱、认证头、邮箱正文或生成服务密钥。
- 分析数据采用明确授权和最小化采集。

## 同步与 API

- 所有生产流量使用 HTTPS。
- 写请求使用幂等键。
- 客户端输入执行大小、格式和 schema version 校验。
- 内容包下载后验证 checksum，再解码和语义校验。

## 用户权利

- 支持数据导出、账号删除和设备会话管理。
- 个人牌谱与能力画像默认私有。
- 删除流程覆盖主数据、对象存储和异步任务残留。
