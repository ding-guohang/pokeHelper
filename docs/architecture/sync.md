# 独立账号与同步架构

## 原则

- 从 M1 开始建设独立账号与云端同步。
- 客户端本地优先，断网时课程、训练和确定性评分继续可用。
- 训练事件不可变、只追加，并使用事件 ID、设备 ID 和幂等键去重。
- 能力画像由完整事件重算，不以某台设备保存的总分为真值。
- 个人牌局与场景采用版本化保存；偏好采用字段级最近修改。

## 数据流

```text
用户完成决策
  → 本地保存 TrainingEvent
  → 写入 Outbox
  → 联网后幂等上传
  → 服务端确认并返回 Checkpoint
  → 拉取其他设备的新事件
  → 本地重算能力画像与今日计划
```

## 服务端边界

- 身份和设备会话。
- 增量同步 API。
- 训练事件持久化和能力画像重算。
- 版本化内容分发。
- M2 牌谱处理任务。
- M4 订阅验证与权益。

## 冲突策略

| 数据 | 策略 |
|---|---|
| 训练事件 | 按事件 ID 幂等追加 |
| 能力画像 | 从事件重算 |
| 个人牌局/场景 | 版本化并保留冲突副本 |
| 用户偏好 | 字段级最近修改 |
| 策略内容 | 不可变版本；历史引用原版本 |

## 隐私边界

- 牌谱和能力画像默认私有。
- 日志不记录完整牌谱、身份凭据或生成服务密钥。
- 必须提供数据导出、账号删除和设备会话管理。
