# 核心学习与评分规则

## 目标用户

- 入口服务已经会玩但主要凭感觉决策的 B 类玩家。
- 长期深度服务训练范围、频率、EV、剥削和赛事策略的 C 类玩家。
- 产品不承担完全新手的完整规则启蒙。

## 学习闭环

```text
诊断 → 今日训练 → 即时教练 → 漏洞画像
     → 间隔复练 → 模拟验证 → 陌生场景迁移
```

## 评分规则

- 同时显示合法性、行动频率、原始 EV、EV 损失和可解释质量等级。
- 实际 runout 和输赢不改变决策评分。
- 多个接近 EV 的行动均可接受。
- 信心用于区分真会、猜对和高信心错误。
- 高信心且明显亏损的错误优先进入后续训练。

## 教练规则

- 先给一句可执行结论，再展示范围、牌面、对手和后续计划。
- 专业模式默认可查看频率、EV、组合、阻断牌和求解假设。
- GTO 基线与剥削建议并列；剥削必须有明确条件。
- 生成式 AI 只组织已有分析，不生成策略真值。

## 掌握规则

能力掌握同时依赖：

- 最小样本。
- 最近表现稳定性。
- 合理信心校准。
- 间隔复练。
- 未见场景中的迁移表现。

重复答对同一道题不能直接判定掌握。
