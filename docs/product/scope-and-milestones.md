# 产品范围与里程碑

## 产品范围

- 现金局主线：线上风格 6-max、100BB、无限注德州扑克。
- 锦标赛扩展：不同筹码深度、Ante、Push/Fold、Rejam、泡沫期和决赛桌 ICM。
- 专业工具：范围、EV、组合、阻断牌、场景构建和文本牌谱导入。
- 平台：iPhone 与 iPad 原生 APP。
- 数据：独立账号、云端同步、本地优先和离线训练。

## 明确排除

- 真钱游戏和俱乐部。
- 玩家现金对战。
- 第三方牌桌实时连接。
- 直播牌桌图像识别。
- 社交动态、排行榜和战队。
- M3 之前的 PKO 赏金模型。

## 里程碑

| 里程碑 | 内容 | 完成条件 |
|---|---|---|
| M1A | 离线现金局教练纵向切片 | iPhone/iPad 决策、专业反馈、事件记录和复盘可运行 |
| M1B | 独立身份与同步 | Apple/邮箱登录、Go API、PostgreSQL 和幂等同步 |
| M1C | 自适应现金局课程 | 诊断、能力树、已审核内容、间隔复练和今日计划 |
| M2A | 现金局 Session | 可复现发牌、虚拟对手和关键手复盘 |
| M2B | 个人牌局实验室 | 牌谱解析、冲突预览、场景构建和分支重放 |
| M3 | 锦标赛扩展 | 短码、赛事路线、泡沫期和 ICM |
| M4 | 商业化 | 订阅、权益、内容运营、隐私和上架 |

M1 只有在 M1A、M1B、M1C 全部通过后完成。
