# 隐私与数据处理（M4 上架地基草稿）

> **状态：内部草稿，非最终隐私政策。** 本文只陈述**当前代码库实际的**数据流，作为
> App Store 隐私材料与《隐私营养标签》的事实底稿。任何对外发布的隐私政策须由所有者
> （必要时含法务）审阅定稿——本文不自我背书为法律文本。凡代码尚未实现的能力，一律
> 标注为「待产品决策」，不编造。
>
> 事实来源：`CLAUDE.md`、`openspec/specs/account-data-rights`、
> `Contracts/training-event-upload-v1.json`、`Server/migrations/*.sql`。

## 1. 收集并存储的数据

### 1.1 账号身份与认证（远端，`Server/` MySQL）
- `users` / `auth_identities`：邮箱注册或 Apple Sign-in 的 subject 标识。
- `password_credentials`：密码仅以**哈希**存储；`email_challenges`：邮箱验证挑战。
- `devices` / `sessions` / `refresh_tokens`：跨设备登录与同步所需的设备与会话记录。
- `auth_throttles`：登录/敏感操作的限流计数。

### 1.2 训练事件（不可变，本机 + 远端 `training_events`）
每次决策产生一条事件，字段见冻结契约 `training-event-upload-v1.json`（`schemaVersion=1`）：
`id`、`localUserID`、`deviceID`、`occurredAt`、`abilityDimension`、`scenarioID`、
`strategyPackID`、`strategyContentVersion`、`submission`（选择的动作 + 信心度）、
`grade`（selectedEV / bestEV / evLoss / lossRate / score / quality / 是否策略可用）。

**关键隐私属性：事件不存储原始牌面。** 手牌、公共牌、位置等由 `scenarioID` 关联已安装
的策略内容包求得，事件本身只记录「哪个场景 + 玩家怎么决策 + 得分」，不含牌谱正文，
也不含自由文本 PII。

### 1.3 本机数据（设备内）
- 训练事件以 JSON Lines 追加式存储；同步 `outbox`、`checkpoint`。
- 内容损坏时的历史备份（corruption backups）。
- Keychain：认证凭据（access/refresh 令牌）。

## 2. 明确**不**收集 / 不存储的数据
- **客户端无第三方运行时依赖**（无广告 SDK、无第三方分析/追踪 SDK）。
- 日志**不**记录完整牌谱、认证头或密钥（`CLAUDE.md` 硬约束）。
- 数据导出**不**包含密码哈希、令牌哈希或邮箱挑战凭据（`account-data-rights`）。
- 训练事件不含姓名、邮箱正文等 PII——身份与训练数据通过 `localUserID` 关联，事件负载
  本身不携带联系方式。

## 3. 用途与最小化
- 训练事件用于：本机评分、能力模型归约（`PlayerModelReducer`）、间隔复练与今日计划。
- 评分只依据结构化内容，**不读取后续发牌或本手输赢**（领域约束）。
- 跨设备同步仅为保持一致的训练进度；采用幂等 outbox 增量上传，事件不可变、永久记录
  生成时的 pack ID 与内容版本（可追溯，不可篡改历史评分）。

## 4. 数据主体权利（`account-data-rights` 已实现）
- **近期重认证门槛**：导出、删除、敏感身份关联需最近一次密码或 Apple 重认证证明；过期
  即拒绝，不返回任何数据、不部分删除。
- **结构化导出**：带 schema version、生成时间与文件清单；远端 JSON 只含本认证用户的账号
  元数据、设备会话与不可变训练事件；本机损坏备份作为独立附件纳入，不自动上传；不含
  任何凭据。
- **删除**：确认后事务删除远端账号（所有远端会话立即失效、清 Keychain），并单独询问是否
  删除本机 profile（事件 / outbox / checkpoint / 损坏备份），不影响其他账号 profile。
- **安全退出**：撤销当前 refresh 会话、清本机凭据，但**不**删除训练历史；离线退出亦立即清
  凭据并锁定该 profile。

## 5. 传输与保留
- 同步经 Go 服务；生产部署须启用 TLS（**待确认**：部署层配置，不在客户端代码内）。
- 训练事件按设计不可变、长期保留（学习进度的真值）；删除路径见第 4 节。

## 6. 年龄与内容分级（待产品决策）
- 应用是德州扑克**策略训练**，面向成人；不含真实货币赌博、不含现金/筹码购买（**待确认**：
  当前无任何充值/博彩功能）。App Store 年龄分级与「模拟赌博」标签的判定需所有者决策。

## 7. 尚未实现、需产品决策后才能填写的部分（**不编造**）
- **遥测 / 分析**：目前无任何分析采集。是否引入「同意式（opt-in）分析」、采集什么口径、
  是否privacy-preserving（不含牌谱/PII），是产品决策——决定后再补契约与本文对应条目。
- **第三方服务**：如崩溃报告、客服、支付网关等——目前均无；引入任一都会改变本文与隐私
  标签，须单列。
- **订阅 / 内购数据**：StoreKit 交易、凭据校验、entitlement 状态尚未实现（M4）；上线订阅后
  需补充「交易标识、订阅状态」的收集与用途说明。

## 8. App Store 隐私标签映射（草稿）
| 数据类型 | 是否收集 | 关联到身份 | 用途 |
|---|---|---|---|
| 联系信息（邮箱） | 是（邮箱注册路径） | 是 | 账号功能 |
| 标识符（Apple subject / localUserID / deviceID） | 是 | 是 | 账号与跨设备同步 |
| 使用数据（训练事件：场景 + 决策 + 评分） | 是 | 是 | 应用功能（学习进度/评分/复练） |
| 用户内容（原始牌谱牌面） | **否**（事件不存牌面） | — | — |
| 诊断 / 崩溃 / 分析 | **否**（当前无） | — | 待产品决策 |
| 位置、联系人、浏览记录、广告标识 | 否 | — | — |

> 上表须在真机构建接入 StoreKit / 任何分析前复核；接入即更新。
